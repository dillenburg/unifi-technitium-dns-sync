# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and the project intends to follow
Semantic Versioning after the first stable release.

## [Unreleased]

### Added

- Public repository documentation and hardened container example.
- Generic environment-only network configuration.
- HTTPS and certificate verification defaults.
- Explicit opt-in for plaintext Technitium HTTP.
- Isolated state-machine tests and GitHub Actions checks.

## [0.1.0] - 2026-09-30

### Added

- UniFi client discovery for one configured IPv4 subnet.
- Dynamic Technitium Primary discovery.
- Crash-safe A/PTR write-ahead journal.
- Recovery with roll-forward and persistent conflicts.
- Targeted retirement journal for superseded and stale records.
- Optional Infisical Universal Auth bootstrap.
